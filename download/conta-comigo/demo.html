Conta Comigo

Mini jogo de matemática para crianças a partir de 4 anos — extensão para navegadores

✅ Chrome ✅ Edge ✅ Brave ✅ Opera ✅ Firefox

👆 Prévia interativa — clique e jogue!

🧩 Instalar no Google Chrome, Edge, Brave ou Opera

  1. Abra chrome://extensions (ou edge://extensions).
  2. Ative o Modo do desenvolvedor no canto superior direito.
  3. Clique em Carregar sem compactação.
  4. Selecione a pasta conta-comigo.
  5. Fixe o ícone 🦊 na barra (ícone de peça de quebra-cabeça → alfinete).

🦊 Instalar no Mozilla Firefox

  1. Abra about:debugging#/runtime/this-firefox.
  2. Clique em Carregar add-on temporário.
  3. Escolha o arquivo manifest.json da pasta conta-comigo.
  4. Clique no ícone 🦊 na barra de ferramentas para jogar.

Dica: para uso permanente no Firefox, o pacote pode ser enviado ao Firefox Add-ons (AMO) para assinatura.
